# Discord: отдельные субтитры для каждого участника

Используется ваш бот в обычном голосовом канале сервера. Бот получает отдельный
аудиопоток каждого говорящего; SubForStream распознаёт его локально и подписывает
реплику ником участника. Одновременные голоса не объединяются в один текст.

## 1. Создайте и добавьте бота

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications).
2. Создайте приложение, например `SubForStream`.
3. В разделе **Bot** получите токен бота (при необходимости **Reset Token**).
4. В настройках установки выберите **Guild Install**, scope **bot** и права
   **View Channels** / «Просматривать каналы», **Connect** / «Подключаться».
   Можно использовать **OAuth2 → URL Generator** с теми же scope и правами.
5. Откройте ссылку установки и добавьте бота на свой сервер.
6. Убедитесь, что права самого голосового канала разрешают боту вход.

Администраторские права, Message Content Intent и команды в чате этому приложению не нужны.
Бот подключается с выключенным собственным микрофоном, но с включённым приёмом звука.

Основа процедуры: [документация Discord](https://docs.discord.com/developers/bots/overview).

## 2. Получите ID канала и свой ID

В Discord откройте **Настройки пользователя → Расширенные → Режим разработчика**.
Нажмите правой кнопкой на голосовой канал → **Копировать ID канала**.
Аналогично можно скопировать собственный ID пользователя.
[Справка Discord об ID](https://support.discord.com/hc/en-us/articles/206346498-Where-can-I-find-my-User-Server-Message-ID).

## 3. Подключитесь из SubForStream

1. Запустите новую сборку и откройте вкладку **Discord**.
2. Вставьте токен **бота** и ID голосового канала.
3. Если одновременно используете локальный микрофон, укажите **Мой Discord ID**:
   ваш голос будет исключён из приёма бота, чтобы не появлялся дважды.
4. Выберите лимит участников (1–8). Движок и язык берутся со вкладки микрофона.
5. Нажмите **Подключить бота**. При первой загрузке выбранной модели дождитесь подготовки.
6. Участники появляются в таблице, когда начинают говорить.

Токен передаётся дочернему процессу через анонимный канал и не сохраняется в
`config.json`, командной строке или журнале. После закрытия приложения его нужно ввести снова.
Аудиофайлы не создаются. Бот не отправляет текстовые сообщения в Discord.

Чтобы остановить обработку, нажмите **Отключить бота**. Локальный микрофон управляется отдельно.
Если бот подключён, но речи нет, проверьте, что он не заглушён по входящему звуку
(server deafen), что участники говорят в выбранном канале и не отключены администратором.

## Оформление

Во вкладке **Оформление** выберите «Диалоговые облачка», «Стекло», «Неон»,
«Комикс», «Минимализм» или «Классика». Нажмите **Сохранить настройки**.
У каждого участника — независимый текст, цвет и таймер скрытия.
В режиме облачков ваш микрофон расположен справа, остальные участники — слева.
При большом числе блоков размер текста уменьшается, чтобы они помещались в сцену.
Лимит видимых блоков регулируется отдельно от числа распознаваемых участников;
при превышении остаются недавно обновлявшиеся блоки.

Кнопка **Показать пример в OBS** выводит три тестовые реплики с текущим оформлением.
Это полезно для настройки сцены без голосового разговора.

## Ограничения и проверка

- Работает с обычными голосовыми каналами серверов; личные звонки и Stage-каналы не подключаются.
- В сборку включены Node.js и библиотеки Discord с поддержкой DAVE; отдельная установка не требуется.
- Вес модели общий для участников Discord, состояние распознавания и очередь — отдельные.
  При большой нагрузке счётчики пропусков в таблице показывают, что обработка не успевает.
- Имя берётся из Discord, а не определяется по сходству голосов. Временно может появиться
  подпись с концом ID, пока библиотека получает ник участника.
- Приём аудио в `@discordjs/voice` не является гарантированным стабильным API Discord:
  после изменений протокола может потребоваться обновление библиотеки.
  [Примечание разработчиков библиотеки](https://discord.js.org/docs/packages/voice/0.19.2).
- Выполнены тесты маршрутизации участников, двух одновременных потоков на готовой записи,
  преобразования Opus → PCM, цензуры и вывода в Chrome. Подключение к вашему живому
  голосовому каналу без токена бота пока не проверялось.
